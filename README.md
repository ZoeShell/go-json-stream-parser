# Go JSON Stream Parser & Validator

Микро-проект на Go, демонстрирующий эффективную потоковую десериализацию (парсинг) JSON-данных из HTTP-запросов и правильную обработку синтаксических ошибок.

## 🛠 Какую проблему решает проект?
В веб-разработке часто используют связку `io.ReadAll` + `json.Unmarshal`. Такой подход заставляет сервер сначала полностью выкачать весь JSON в оперативную память (выделяя под него промежуточный буфер), и только потом разбирать. Если клиент пришлет огромный файл или битый JSON, сервер потратит ресурсы впустую, а в случае проигнорированной ошибки `err` продолжит работать с пустой или сломанной структурой данных.

## 🚀 Решение
В данном проекте реализовано два уровня защиты продакшн-кода:
1. **Потоковый парсинг:** Вместо выкачивания всего текста в память используется конструктор:
   ```go
   json.NewDecoder(r.Body).Decode(&user)
   ```
   Он стримит данные напрямую из сетевого сокета и парсит их на лету, что минимизирует аллокации памяти (важно для Highload-систем).
2. **Явная обработка ошибок:** Код строго проверяет возвращаемую ошибку `if err != nil`. При синтаксическом сбое (например, если пропущена закрывающая скобка JSON) хендлер мгновенно прерывает работу и отдает клиенту корректный статус `400 Bad Request`.

## 🧫 Тестирование
В коде реализована симуляция обработки поврежденного JSON-пакета (намеренно пропущена закрывающая фигурная скобка). Тест проверяет перехват ошибки встроенным декодером с помощью пакета `net/http/httptest`.
